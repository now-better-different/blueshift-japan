# Blueshift Gmail Logo（Chrome拡張機能）

Gmailの画面左上にある **Google / Gmailのロゴ** を、**Blueshiftの自社ロゴ**に
強制的に置き換えるための、自作Chrome拡張機能です。

> ⚠️ この拡張機能は「インストールしたパソコンのChrome」でのみ有効です。
> 他の社員のパソコンにも反映させたい場合は、各自のChromeに入れるか、
> Chromeの企業管理機能（Google Admin）で一括配信してください。

---

## 中身のファイル

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の設定ファイル（Manifest V3） |
| `content.js` | ロゴを探して自社ロゴに置き換える本体スクリプト |
| `content.css` | 表示を安定させる補助スタイル |
| `logo.png` | 表示する自社ロゴ画像（差し替え可） |
| `icon128.png` | 拡張機能のアイコン |

自社ロゴを変えたい場合は、この `logo.png` を好きな画像（同じファイル名）に
置き換えるだけでOKです。

---

## インストール手順（開発者モードで読み込む）

1. Chromeで `chrome://extensions` を開きます
   （右上の「︙」＞「拡張機能」＞「拡張機能を管理」でも同じ画面です）。
2. 画面右上の **「デベロッパー モード」** をオンにします。
3. 左上に出てくる **「パッケージ化されていない拡張機能を読み込む」** を
   クリックします。
4. この `gmail-logo-extension` フォルダを選択します。
5. Gmailのタブを開き直す（リロードする）と、左上のロゴが
   自社ロゴに置き換わります。

---

## 調整のしかた

`content.js` の先頭にある次の値を変えると、見た目を調整できます。

```js
const LOGO_HEIGHT = "40px";      // ロゴの高さ
const LOGO_MIN_WIDTH = "120px";  // ロゴの最小幅
```

- ロゴが小さい / 大きい → `LOGO_HEIGHT` を調整
- ロゴの右側が切れる / 空きすぎる → `LOGO_MIN_WIDTH` を調整

変更後は `chrome://extensions` の画面で、この拡張機能の
**「更新（再読み込み）」ボタン**を押してから、Gmailをリロードしてください。

---

## うまく置き換わらないときは

Googleが **Gmailの画面構造（HTMLのタグや属性）をアップデートすると、
ロゴを見つけられなくなる**ことがあります。その場合は `content.js` の
セレクタ（`CONTAINER_SELECTORS` / `IMAGE_SELECTORS`）を、実際の
ロゴ要素に合わせて調整する必要があります。

調べ方の目安：

1. Gmailで左上のロゴを右クリック →「検証（Inspect）」
2. ハイライトされた要素の `aria-label` / `alt` / `href` などを確認
3. その値に合わせて `content.js` のセレクタを追加・修正

---

## 注意事項

- この拡張機能は Gmail(`mail.google.com`) の画面上でのみ動作します。
- 見た目だけを書き換えるものです。送受信の動作やメール内容には影響しません。
- Google公式の機能ではなく、Blueshift社内向けの自作ツールです。
